# Repositorio de Programación Orientada a Objetos (POO) y Patrones de Diseño en Python

Repositorio académico y práctico diseñado para demostrar la aplicación de la **Programación Orientada a Objetos (POO)** y **Patrones de Diseño** en Python moderno, utilizando buenas prácticas de ingeniería de software.

## 🛠️ Tecnologías y Herramientas
- **Lenguaje:** Python 3.x (Biblioteca estándar, sin dependencias externas).
- **Editor:** Visual Studio Code.
- **Control de versiones:** Git y GitHub.
- **Documentación:** Markdown.

---

## 📋 Contenido del Repositorio

| N.º | Nombre del Ejercicio | Patrón de Diseño | Categoría |
| :---: | :--- | :--- | :--- |
| **1** | Gestor de Configuración Global | Singleton | Creacional |
| **2** | Fábrica de Notificaciones | Factory Method | Creacional |
| **3** | Configurador de Vehículos Personalizados | Builder | Creacional |
| **4** | Adaptador de Pasarelas de Pago | Adapter | Estructural |
| **5** | Envíos con Servicios Adicionales | Decorator | Estructural |
| **6** | Calculadora de Tarifas de Envío | Strategy | Comportamiento |
| **7** | Estación Meteorológica Inteligente | Observer | Comportamiento |
